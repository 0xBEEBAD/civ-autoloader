# Compatibility

## Switch 2, firmware 23.0.1

Working path:

```text
CivSwitch userland -> CivSwitchFS -> kaiHEN -> hbmenu
```

The CFS overlay and kaiHEN binaries in this repository are the tested
combination.

## Other firmware

Only Switch 2 firmware 23.0.1 is supported by this build. Switch 1 is not
supported.
